# ValheimWings Mod

## Requisitos previos
- El juego Valheim instalado.
- BepInEx Pack para Valheim instalado.

## ¿Cómo obtener BepInEx?
El mod requiere BepInEx para funcionar. Si aún no lo tienes:
1. Visita la página oficial de BepInEx en Thunderstore: https://valheim.thunderstore.io/package/denikson/BepInExPack_Valheim/
2. Descarga la última versión.
3. Extrae el contenido en la carpeta raíz de tu juego (donde está el ejecutable valheim.exe).

## Instalación del Mod
1. Asegúrate de haber instalado BepInEx correctamente.
2. Ve a la carpeta `BepInEx` en la raíz de tu juego.
3. Si no existe una carpeta llamada `plugins` dentro de `BepInEx`, créala manualmente.
4. Copia el archivo `ValheimWings.dll` que viene en este paquete y pégalo dentro de `BepInEx/plugins/`.
5. Inicia el juego. 

*Nota: Al iniciar el juego por primera vez con el mod, se generará automáticamente un archivo de configuración en BepInEx/config/ValheimWings.cfg para personalizar parámetros si lo deseas.*
